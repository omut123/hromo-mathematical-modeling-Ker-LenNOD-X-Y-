## О проекте

Программа для визуализации числовых закономерностей методом **хромоматематического моделирования** (HMM).  

Мы берём скучные целые числа и раскрашиваем их так, чтобы скрытые паттерны становились видимыми невооружённым глазом.

### Объекты исследования

| Объект | Что это | Формула |
|--------|---------|---------|
| **1D** | Последовательность квадратов натуральных чисел | \( a_n = n^2 \) |
| **2D** | Ядро длины алгоритма Евклида | \( Z = \mathrm{Ker}(\mathrm{LenNOD}(X, Y)) \) |

---

## Возможности

- **5 хромоматематических моделей**:
  - `HMM_N` — монохром по модулю N
  - `HMM_N2` — расширенная монохромная
  - `HMM_B` — биградиентная
  - `HMM_R` — мультиградиентная
  - `HMM_DN` — дискретная с чёткими границами

- **4 визуализации для 1D**:
  - Спираль Архимеда
  - Замощение плоскости
  - Столбчатая диаграмма
  - Линейный график

- **4 визуализации для 2D**:
  - Цветовая карта (Heatmap)
  - 3D-поверхность
  - Контурный график
  - Профильное сечение

- База данных SQLite (1000+ значений для 1D, 10 000 для 2D)
- Выбор параметров моделирования в реальном времени
- Справочная система
- Экспорт изображений
